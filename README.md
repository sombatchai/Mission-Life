# Mission Life: เปลี่ยนชีวิตประจำวันให้กลายเป็นเกม

**Mission Life** เป็นแอปพลิเคชันมือถือที่เปลี่ยนกิจวัตรและเป้าหมายในชีวิตประจำวันให้เป็น **ภารกิจ (Quest)** แบบเกม ทำภารกิจสำเร็จแล้วได้ค่าประสบการณ์ (XP) เลเวลอัป และสะสมถ้วยรางวัล เพื่อให้การพัฒนาตัวเองสนุกและทำได้ต่อเนื่อง

โครงงานรายวิชา **1101103 โครงงานการพัฒนาโปรแกรมประยุกต์ด้วยภาษาสคริปต์** (กลุ่ม G03)
สาขาเทคโนโลยีดิจิทัล สำนักวิชาศาสตร์และศิลป์ดิจิทัล **มหาวิทยาลัยเทคโนโลยีสุรนารี**

---

## โปรเจคนี้เกี่ยวกับอะไร

หลายคนตั้งเป้าหมายจะสร้างนิสัยที่ดี เช่น ออกกำลังกาย อ่านหนังสือ หรือเก็บเงิน แต่มักเลิกกลางทางภายในไม่กี่สัปดาห์ เพราะกิจวัตรซ้ำซากน่าเบื่อ และต้องรอนานกว่าจะเห็นผล

Mission Life ใช้กลไกเกมและจิตวิทยาพฤติกรรมมาช่วย โดยเปลี่ยนเป้าหมายใหญ่ให้เป็นภารกิจเล็กๆ ที่ทำได้ทุกวัน และให้รางวัลทันทีที่ทำสำเร็จ ผู้ใช้จึงเห็นความคืบหน้าของตัวเองชัดเจนและอยากทำต่อ

### วัตถุประสงค์

1. พัฒนาแอปที่ช่วยบันทึกและติดตามการพัฒนาตนเอง
2. สร้างแรงจูงใจให้ผู้ใช้ทำกิจกรรมที่มีประโยชน์ต่อตัวเองอย่างสม่ำเสมอ
3. เปลี่ยนกิจวัตรที่ยากหรือน่าเบื่อให้สนุกและจับต้องได้ ผ่านค่าประสบการณ์และเลเวล
4. แสดงพัฒนาการของผู้ใช้เป็นข้อมูลและสถิติที่ชัดเจน แทนการประเมินจากความรู้สึก

### แนวคิดหลัก

- **Life-to-Game Synthesis**: เปลี่ยนพฤติกรรมจริงให้เป็นค่าสถานะในเกม ใช้ชีวิตเหมือนออกผจญภัย
- **Visualized Achievement**: เปลี่ยนความพยายามที่มองไม่เห็นให้เป็นกราฟิกและสถิติที่จับต้องได้
- **Gamified Discipline**: ใช้ระบบรางวัลจูงใจให้เรื่องยากกลายเป็นเรื่องสนุก

## ฟีเจอร์

### แอปผู้ใช้ (มือถือ)

| ฟีเจอร์ | รายละเอียด |
|---|---|
| **บัญชีผู้ใช้** | สมัครสมาชิก เข้าสู่ระบบ ลืมรหัสผ่าน (ยืนยันด้วย OTP ทางอีเมล) และเปลี่ยนรหัสผ่าน |
| **สร้างตัวละคร** | ตั้งชื่อตัวละครและเลือกรูปโปรไฟล์จากคลังภาพในเครื่อง |
| **สร้างภารกิจ** | กำหนดชื่อ หมวดหมู่ (เช่น สุขภาพ การเรียน การเงิน) ระยะเวลา และความยาก ซึ่งให้ XP ต่างกัน: ง่าย 30 / ปานกลาง 60 / ยาก 100 |
| **บอสมอนสเตอร์** | เลือกรูปมอนสเตอร์หรืออัปโหลดรูปเองเป็นบอสของภารกิจ แล้ว "ต่อสู้" ด้วยการทำภารกิจให้สำเร็จ |
| **ภารกิจที่กำลังทำ** | ดูรายการภารกิจพร้อมแถบความคืบหน้า |
| **สถิติและประวัติ** | กราฟวงกลมเทียบภารกิจที่สำเร็จกับล้มเหลว และประวัติภารกิจย้อนหลังทั้งหมด |
| **ห้องถ้วยรางวัล** | สะสมความสำเร็จเมื่อทำได้ตามเงื่อนไข |
| **ข้อเสนอแนะ** | ส่งความคิดเห็นหรือแจ้งปัญหาถึงผู้ดูแลระบบ |

### ระบบผู้ดูแล (เว็บ)

| ฟีเจอร์ | รายละเอียด |
|---|---|
| **Dashboard** | จำนวนผู้ใช้ทั้งหมด ผู้ใช้ที่กำลังใช้งาน จำนวนภารกิจ อันดับผู้ใช้ และสถิติผู้เข้าใช้รายวัน |
| **จัดการภารกิจ** | ดูภารกิจทั้งหมดในระบบ สร้างภารกิจส่งให้ผู้ใช้รายคนหรือทุกคน และแก้ไขหรือลบภารกิจ |
| **จัดการผู้ใช้** | ดูรายชื่อผู้ใช้ (ID, อีเมล, เลเวล) และแก้ไข Username วันเกิด และเลเวลได้ ส่วน ID และอีเมลแก้ไม่ได้ |
| **Feedback** | อ่านข้อเสนอแนะและปัญหาที่ผู้ใช้ส่งมา |

## ใครเกี่ยวข้องกับระบบนี้

### ผู้ใช้งานระบบ

| ผู้ใช้ | ทำอะไรได้บ้าง |
|---|---|
| **ผู้ใช้ทั่วไป (User)** | ใช้แอปบนมือถือ สร้างตัวละคร สร้างและทำภารกิจ สะสม XP และดูสถิติของตัวเอง |
| **ผู้ดูแลระบบ (Admin)** | ใช้เว็บหลังบ้าน (ล็อกอินแยกจากผู้ใช้ทั่วไป) จัดการภารกิจกลาง ข้อมูลผู้ใช้ และอ่าน Feedback |

### ผู้ได้รับประโยชน์

- **ผู้ที่อยากพัฒนาตัวเอง**: สร้างวินัยและนิสัยที่ดีได้ยั่งยืน รักษาแรงจูงใจระยะยาว และมั่นใจในตัวเองมากขึ้นเมื่อทำภารกิจเล็กๆ สำเร็จ
- **สังคมโดยรวม**: เมื่อผู้คนมีวินัยและสุขภาพดีขึ้น ประสิทธิภาพการทำงานและคุณภาพชีวิตก็ดีขึ้นตาม

### ผู้จัดทำ

| ชื่อ-สกุล |
|---|
|  นายสมบัติชัย คำขาว |
| นายศิริชัย เทียบพา |
| นายณัฐภูมิ อยู่คง |
| นายชาติธาดา สายน้อย |
| นายธนากร เชื่อมาก |
| นางสาวสินิทรา ชาติทอง |

## โครงสร้างโปรเจค

```
Mission-Life/
├── Admin/
│   ├── BackendSystem/     Express API สำหรับเว็บผู้ดูแล (พอร์ต 3000)
│   └── frontendAdmin/     หน้าเว็บผู้ดูแล: Login, Dashboard, Quest, Personal, Feedback
└── user/
    └── my-app/            แอปมือถือ (Expo / React Native)
```

## วิธีรันโปรแกรม

**เว็บผู้ดูแลระบบ**

```bash
cd Admin
npm install
node BackendSystem/Server.js
```


ต้องมีไฟล์ `Admin/BackendSystem/serviceAccountKey.json` ของโปรเจค Firebase ตัวเอง (ดาวน์โหลดได้จาก Firebase Console → Project settings → Service accounts) ไฟล์นี้เป็นความลับ **ห้าม commit ขึ้น GitHub**

**แอปผู้ใช้**

```bash
cd user/my-app
npm install
npx expo start
```

สแกน QR Code ด้วยแอป **Expo Go** บนมือถือ หรือกด `a` เพื่อเปิดใน Android Emulator
